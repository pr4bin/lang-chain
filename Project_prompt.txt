### **1. Project Overview: Semantic Search Engine**

**One-sentence description:** A production search system that combines dense vector retrieval (using BERT embeddings) with a learning-to-rank model to surface relevant results in milliseconds across millions of documents.

**Real-world use case:** Every major tech company needs internally optimized search. This project solves the exact problem Google Search, Microsoft Bing, and Meta Search tackle at scale, demonstrating the ability to build systems requiring sub-100ms latency at massive scale. A 10% improvement in search quality directly increases platform engagement and conversion rates.

### **3. Comprehensive Tech Stack**

This tech stack is modern, industry-standard, and specifically chosen to demonstrate FAANG-level technical depth:

**Frontend:**
*   **React 18 + TypeScript:** For building type-safe, scalable, and maintainable user interfaces.
*   **TailwindCSS:** A utility-first CSS framework for rapid and consistent styling.
*   **Recharts:** For creating interactive data visualizations for analytics dashboards.
*   **Axios:** A promise-based HTTP client for making API requests.
*   **Port:** 3000

**Backend:**
*   **FastAPI 0.104+:** A modern, fast (high-performance), async-ready Python web framework with automatic documentation.
*   **Uvicorn (dev) + Gunicorn (prod):** For serving the FastAPI application efficiently in both development and production environments.
*   **Pydantic:** For robust data validation and settings management.
*   **Python 3.11+:** The primary language for backend and ML components.
*   **Port:** 8000

**Search & Retrieval:**
*   **Elasticsearch 8.x:** A powerful search and analytics engine supporting both BM25 (lexical) and dense vector search for hybrid retrieval.
    *   **Document Fields:** `id`, `title`, `content`, `embeddings`.
    *   **Port:** 9200
*   **Sentence-Transformers 2.2.2 (Model: `all-MiniLM-L6-v2`):** For generating high-quality, efficient embeddings (384 dimensions) for semantic search.

**Ranking & Machine Learning:**
*   **LightGBM 4.1+:** A fast, distributed gradient boosting framework, specifically used for Learning-to-Rank (LambdaMART).
    *   **Objective:** `rank:ndcg`
    *   **Metric:** NDCG (Normalized Discounted Cumulative Gain)
*   **scikit-learn:** For various ML utilities and metrics calculation.
*   **NumPy/Pandas:** Essential libraries for data processing and numerical operations.

**Caching:**
*   **Redis 7.x:** An in-memory data store used for caching query results (TTL: 24h) and embeddings (TTL: 7d) to significantly improve performance.
    *   **Port:** 6379

**Database:**
*   **PostgreSQL 14+:** A robust relational database for storing metadata (e.g., `documents`, `search_logs`, `model_metadata`).
    *   **Port:** 5432
*   **SQLAlchemy:** An Object Relational Mapper (ORM) for Python.
*   **Alembic:** For database migrations.

**Containerization:**
*   **Docker + Docker Compose:** For creating reproducible development environments and orchestrating multi-service applications locally.
*   **Kubernetes (optional):** Mentioned as a scalable deployment option, demonstrating awareness of advanced orchestration.

**Deployment:**
*   **AWS EC2 / ECS Fargate / Google Cloud Run:** Cloud platforms for deploying the application.
*   **Nginx:** As a reverse proxy and for SSL termination in production.

**Monitoring & Logging:**
*   **Structlog:** For structured JSON logging, crucial for effective log analysis.
*   **Prometheus:** For collecting and monitoring application metrics.
*   **CloudWatch / ELK Stack:** For centralized log aggregation and analysis.

**Development & Testing:**
*   **Pytest:** A powerful Python testing framework.
*   **Black:** An uncompromising Python code formatter.
*   **Ruff:** An extremely fast Python linter.
*   **GitHub Actions:** For Continuous Integration/Continuous Deployment (CI/CD).

### **4. Detailed Implementation Roadmap (12-16 Weeks)**

This routine balances learning and implementation, designed for approximately **15-20 hours per week**.

**📊 Roadmap Overview**

| Phase             | Duration    | Focus                     | Hours/Week | Deliverable                 |
| :---------------- | :---------- | :------------------------ | :--------- | :-------------------------- |
| **Phase 1**       | Weeks 1-4   | Foundation & Learning     | 18-20      | Production-ready backend    |
| **Phase 2**       | Weeks 5-7   | LTR Training              | 18-20      | Trained ranking model       |
| **Phase 3**       | Weeks 8-10  | Frontend & Deploy         | 18-20      | Live on AWS/GCP             |
| **Phase 4**       | Weeks 11-12 | Polish & Portfolio        | 12-15      | Interview-ready             |
| **Total**         | **12 weeks**| **Full MVP**              | **~18/week** | **240-280 hours**           |

---

**🎯 The 4 Phases Explained**

**PHASE 1: FOUNDATION & LEARNING (Weeks 1-4)**
*   **Week 1:** Docker + Elasticsearch setup, BM25 search implementation.
*   **Week 2:** Dense embeddings integration, hybrid search (BM25 + dense vectors).
*   **Week 3:** Learning-to-Rank (LambdaMART) concepts, initial data labeling for training.
*   **Week 4:** Build production-ready backend with FastAPI, Dockerize services, implement unit tests.
*   **Deliverable:** Working backend MVP with hybrid search, Dockerized services, and initial test coverage.

**PHASE 2: LEARNING-TO-RANK TRAINING (Weeks 5-7)**
*   **Week 5:** Train the LambdaMART model using LightGBM, aiming for 5-10% NDCG improvement over baseline.
*   **Week 6:** Implement a basic A/B testing framework to validate model improvements.
*   **Week 7:** Optimize the search pipeline for performance (<100ms p99 latency), achieve 60-80% cache hit ratio with Redis.
*   **Deliverable:** Production-ready backend with an integrated and optimized ranking model.

**PHASE 3: FRONTEND & DEPLOYMENT (Weeks 8-10)**
*   **Week 8:** Develop the React/TypeScript search interface, displaying results from the backend.
*   **Week 9:** Build an analytics dashboard within the frontend (using Recharts) and implement a user feedback/rating system.
*   **Week 10:** Deploy the full-stack application to AWS/GCP, set up monitoring (Prometheus, CloudWatch/ELK) and CI/CD (GitHub Actions).
*   **Deliverable:** Full-stack application deployed to the cloud with active monitoring.

**PHASE 4: PRODUCTION POLISH (Weeks 11-12)**
*   **Week 11:** Comprehensive documentation (README, architectural decisions), GitHub repository cleanup and polish.
*   **Week 12:** Create a 5-10 minute demo video, write a blog post explaining the project, and launch on LinkedIn.
*   **Deliverable:** Interview-ready project with all supporting materials.
